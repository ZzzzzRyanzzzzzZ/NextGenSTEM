# NextGen STEM Hackathon

The website for the NextGen STEM Hackathon, Saturday, November 28, 2026.

Hosted on Vercel. Every push to `main` deploys.

| File | What it is |
|---|---|
| `index.html` / `register.js` | The registration page and form |
| `style.css` | All the styling |
| `404.html` | Shown for addresses that don't exist |

## Before you launch

1. Registrations are emailed to nextgenstem42@gmail.com through FormSubmit (formsubmit.co).
   The very first sign-up sends an activation email to that inbox. Click the link in it once,
   or nothing gets delivered.
2. In `index.html`, replace each `TBA` with the venue and time.
3. Add your custom domain in Vercel under Settings → Domains.

## Run it locally

`python3 -m http.server`, then open http://localhost:8000.
